Mission 2026 — UI mockup

A clickable prototype of the redesign. Layout is ported from the proven Momentum habit tracker already in this repo (row-based habit cards, HabitBull-style grid table, dense dark theme), then extended with the new requirements: per-habit notes, In Progress study tab, structured workouts, full goal lifecycle with pace analysis, and a Vision Board tab. Scroll inside each phone; the bottom nav works.

Accent — done / primary action Blue — info / study Amber — streak, at-risk, paused Rose — missed / delete / burnout Violet — goals, notes
